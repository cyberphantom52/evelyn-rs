# Evelyn : A Universal Porting Script
## Description:
> Sidha Zip XD
## Features:
* Single Click GSI creation
* Firmware Detection
* Dynamic Device Support
* Device Specfic Patching
* Multi Firmware Support
* Auto update updater-script with information
* Flashable Zip Creation
* Test build support
* Patch APKs (OxygenOS Only)
## Installation:
```
git clone --recurse-submodules https://github.com/Cyber-Phantom/evelyn.git
```
## Requirements:
- JDK 11, 7z
- apktool
- Python
